# Catch-a-Peak-Rhythm

# Descrition 
time your button presses correctly and slowly reach the summit, let down your guard and miss a note may cause you to start at the very bottom again.

# Gameplay

Ready your hands to press these keys when it show up :
- Q
- W
- E
- A
- S
- D

Space - pause

# Why I made this game
I am a beginner and I think to myself, it would be fun to challenge yourself to create a rhythm game. It may not seem as good as other rhythm game but I will slowly get there such as features like songs, levels, and 3 lives etc... also this was this week theme
